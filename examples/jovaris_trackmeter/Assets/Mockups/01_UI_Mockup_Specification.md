# Jovaris Audio — Track Meter v1.0
## UI 목업 설계서 (Codex 전달용)

**문서 목적:** 기존 JOA_Plugin 프로젝트에서 제작한 Track Meter 이미지 목업 3장을 기준으로, JUCE 8에서 UI를 구현하기 위한 시각·상호작용 명세를 정리한다. **HTML 목업은 없다.** 실제 디자인 기준은 Codex에 별도 전달하는 원본 이미지 3장이다.

> **우선순위:** 원본 목업 이미지(시각 디자인) → 이 문서(레이아웃·동작 규칙) → 제공된 기존 `PluginEditor`/`PluginProcessor` 코드(구현 출발점). 서로 어긋나면 디자인은 목업을 우선하되, 해결할 수 없는 충돌은 임의로 처리하지 말고 보고한다.

## 1. 제품 범위

- **제품명:** Jovaris Track Meter / Jovaris Audio의 세 번째 플러그인(03).
- **목적:** 개별 트랙용으로 작고 빠르게 읽히는 **Sample Peak + Analog VU** 동시 표시.
- **채널:** 스테레오 L/R 각각 Peak 및 VU 표시. 모노 입력에서는 UI에 L=R 동일 측정값 표시.
- **기준:** `0 VU = -18 dBFS RMS` (1 kHz 사인파 기준). Peak는 **Sample Peak**, VU는 평균정류 기반의 동특성을 지닌 계기이며 **별도 RMS 표시기가 아님**.
- **제외:** 별도 RMS 미터, LUFS, True Peak, Correlation, 위상계, Spectrum Analyzer, Gain 조정 기능.
- **오디오:** 측정 전용 통과형. 신호 수정 없음, 추가 지연 0 samples 지향. 실제 동작은 별도 테스트로 검증.

## 2. 시각 디자인 기준

- 원본 3개 목업의 **검정·차콜 계열 금속 패널**, 얇은 **브론즈/골드 포인트**, 따뜻한 **크림색 아날로그 VU 눈금면**을 유지한다.
- 상단 브랜드 `JOVARIS AUDIO`, 중앙 또는 상단 제목 `TRACK METER`, 제품 번호 `03`을 목업 기준으로 배치한다.
- VU 계기: 어두운 베젤, 따뜻한 밝은 다이얼, 검은 바늘, 우측 **붉은 과입력 눈금**, L/R 채널 식별.
- Peak: L/R 세로 LED 막대, dBFS 눈금, 각 채널의 수치 리드아웃, 클립 표시. 목업의 막대 간격과 패널 비례를 우선한다.
- `PEAK HOLD`, `RESET`, `H`/`V` 전환의 버튼 표현은 확정 동작을 반영한다. 목업에 없는 버튼은 주변 스타일과 통일하되 과장하지 않는다.
- 하단 오른쪽 작은 글씨 `Designed by WH`를 유지한다. 다른 영역과 겹치지 않도록 한다.
- **원본 목업 이미지가 제공되지 않았거나 특정 디테일이 불명확하면 그 부분을 확정된 색상 코드·픽셀 위치인 것처럼 추정하지 않는다.**

## 3. 레이아웃

### A. Horizontal (가로형)

- **초기 구현 기준 크기:** `800 × 380` (JUCE 논리 픽셀; 기존 소스의 기본 크기). 실제 창 크기 및 비율은 원본 가로형 목업과 비교해 조정 가능.
- **상단 헤더:** 브랜드 / 제품명 / 번호 / H·V 전환.
- **왼쪽:** Peak L/R, dBFS 눈금, 수치 리드아웃, 채널명, 클립, Peak Hold·Reset.
- **오른쪽:** 나란히 배치한 아날로그 VU L/R 두 개.
- **하단:** `0 VU = -18 dBFS` 및 `Designed by WH`.
- Peak 영역과 VU 영역은 경계가 분명해야 하며 레이아웃 변경 시 텍스트·눈금이 잘리지 않아야 한다.

### B. Vertical (세로형)

- **초기 구현 기준 크기:** `400 × 800` (기존 소스 기준).
- **위에서 아래로:** 헤더 → Peak L/R → Hold/Reset → VU L → VU R → 푸터.
- 두 VU 계기는 수직으로 쌓고, 같은 크기와 눈금 스케일을 유지한다.
- 단순히 가로형 화면 전체를 축소·회전하지 않는다. 실제 배치를 재구성하여 숫자와 바늘이 읽히도록 한다.
- 원본 세로형 목업의 간격과 비례를 우선하고, 좁은 패널에서 Clip·Hold·수치 표시가 겹치지 않도록 한다.

## 4. Peak 패널 상세

- **L/R 독립:** 서로 다른 오디오 신호에 따라 막대와 수치가 별도로 움직인다.
- **표시 범위:** 막대 약 `-60 ~ 0 dBFS`. 0 dBFS 초과 float 신호는 막대 최상단에 머물 수 있으나 **수치에는 +값**을 표시한다.
- **수치:** 일반 상태에서는 실시간 피크 추정 표시, 무음이 충분히 지속되면 `-inf` 표시.
- **클립:** 각 채널의 Sample Peak가 `>= 0 dBFS`일 때 감지. Hold OFF에서는 짧은 램프 유지, Hold ON에서는 기록된 클립 상태를 표시.
- **PEAK HOLD OFF:** 현재 Peak 숫자·실시간 막대 표시. 최고값은 백그라운드에서 계속 기록.
- **PEAK HOLD ON:** 최고 Peak 숫자·Hold 마커 표시. 실시간 막대는 계속 움직임. Hold를 끄고 다시 켜도 기록 유지.
- **RESET:** L/R 최고 Peak, Hold 마커, 기록 클립 및 관련 표시 캐시를 초기화. **VU나 신호 흐름은 중단·리셋하지 않는다.** 재생 중 0 dBFS 이상 신호가 계속되면 클립 재점등은 정상.
- 버튼 ON/OFF를 작은 LED에만 의존하지 않고 버튼 테두리/텍스트 등으로도 구별 가능하게 한다.

## 5. 아날로그 VU 계기 상세

- **L/R 독립 바늘**, 각각 눈금 `-20 ~ +3 VU` 및 `0 VU` 근처 붉은 구간.
- 내부 측정 기준은 **1 kHz 사인파의 -18 dBFS RMS 입력에서 약 0 VU**. 사인파 발생기의 Peak/RMS 기준 차이에 주의.
- 300 ms 수준의 VU 응답 특성을 검증하며, 상승·하강·오버슈트는 실제 측정 결과에 따라 조정. **예쁜 흔들림을 위해 가짜 바늘 진동을 추가하지 않음.**
- UI 바늘 각도와 인쇄 눈금은 **동일한 매핑 규칙**을 사용하고, -20·-10·-7·-3·0·+3 부근에서 표시 정합성을 확인한다.
- 무음이면 바늘이 정상적으로 최저 위치로 돌아가야 한다.
- Retina/HiDPI에서 눈금·세밀한 선·작은 글자가 또렷해야 하며, 작은 계기에도 눈금이 겹치지 않아야 한다.

## 6. H/V 전환과 상태

- H/V 버튼은 **한쪽만 선택**되도록 한다.
- 전환 즉시 패널과 창 크기가 해당 모드에 맞게 변경된다. Logic Pro 호스트 창이 실제로 리사이즈되는지 수동 확인 필요.
- 전환 도중에도 오디오 측정, VU 바늘 상태, 기록된 최고 Peak 및 Clip 상태가 유지된다.
- **프로젝트에 저장/복원:** H/V 선택, Peak Hold ON/OFF.
- **프로젝트에 저장하지 않음:** 실제 Peak 측정값, 최고 Peak 기록, Clip 기록, 순간 VU 값. 세션 재개 시 새로 측정한다.
- 플러그인 **창만 닫았다 다시 여는 경우**와 **Logic 프로젝트를 종료 후 다시 여는 경우**를 분리하여 테스트한다.

## 7. 구현 원칙 (JUCE 8)

- CMake 기반 AU/VST3 프로젝트. 별도의 HTML 또는 Projucer UI 프로젝트가 필수인 것은 아니다.
- JUCE `Graphics`/컴포넌트로 UI를 구현하고, 원본 목업을 바탕으로 레이아웃을 맞춘다.
- 기존 `PluginEditor.cpp/.h`, `PluginProcessor.cpp/.h`를 출발점으로 사용하되, 단순히 현재 코드의 레이아웃을 정답으로 간주하지 않는다.
- 오디오 스레드에서 GUI 렌더링, Lock, 동적 할당을 수행하지 않는다. 공유 측정 상태의 스레드 안전성을 검토한다.
- GUI 기본 업데이트는 **30 Hz**, 실제 CPU 측정 결과에 따라 조정한다.
- 헤더/패널/미터 크기를 변경해도 왜곡·클리핑이 없어야 한다.

## 8. 검수 항목 (사용자/Logic Pro)

- [ ] 가로형이 원본 가로 목업의 비율과 배치를 재현한다.
- [ ] 세로형이 원본 세로 목업의 위→아래 흐름을 재현한다.
- [ ] 제품명, `03`, 브랜드, `Designed by WH`가 정확히 표시된다.
- [ ] Peak L/R 막대와 클립 램프, 수치가 채널별로 독립적이다.
- [ ] Peak Hold ON/OFF와 Reset 동작이 명확하다.
- [ ] VU L/R 눈금, 바늘, 붉은 구간이 정확하고 선명하다.
- [ ] `0 VU = -18 dBFS RMS` 기준이 테스트 신호와 맞는다.
- [ ] H/V 전환 시 바늘·눈금·버튼·글자가 겹치거나 잘리지 않는다.
- [ ] H/V 전환 후 Hold 최고값과 클립 기록이 유지된다.
- [ ] 프로젝트 저장/재오픈 시 H/V 및 Hold 상태가 복원된다.
- [ ] 모노에서는 L/R 같은 값을 표시한다.
- [ ] 실제 오디오에 레벨·음색·지연 변화가 없다.
- [ ] 다중 트랙 인스턴스에서 CPU와 UI 반응이 적절하다.

## 9. Codex에게 전달할 주의사항

1. 이 문서는 **목업 재현을 위한 UI 설계서**다. 정밀한 DSP 및 빌드 테스트는 별도 통합 구현·검수 지시서의 범위다.
2. **사용자가 보관한 원본 이미지 3장**을 프로젝트 `Assets/Mockups/` 등에 함께 넣고 비교한다. 임의로 새 목업이나 HTML 페이지를 만들어 기존 디자인을 대체하지 않는다.
3. 현재 Mac에는 JUCE 8, Xcode, CMake가 이미 설치되어 있다. **Track Meter 자체의 폴더와 Xcode 프로젝트만 없는 상태**이므로 기존 개발 도구를 재설치하지 말고 새 CMake 프로젝트를 생성한다.
4. 목업과 코드 사이의 차이는 **시각적 차이 / 동작 차이**로 분류해 보고한다. UI를 맞추기 위해 측정 정확도를 희생하지 않는다.
5. 확인되지 않은 픽셀 단위의 디자인 수치나 실제 Logic 동작을 임의로 PASS 처리하지 않는다.
