# Jovaris Track Meter Trial 0.1.4 — Mac 수정·검증

2026-10-31 KST. 실제 환경: Apple Silicon arm64, macOS 15.8, Logic Pro 12.3.1.

## 확인된 원인과 경계

설치돼 있던 0.1.3 AU와 ZIP 소스로 만든 AU를 실제 네이티브 테스트 호스트에서 비교했다. 오디오 블록이 계속 들어올 때 입력 .2→.02 변화, 무음 복귀, Hold/Clip 및 Reset 전달은 둘 다 통과했다. 따라서 원래 사용자가 보고한 **다른 음원 재생 중 고정 증상 전체의 원인이 확정됐다고 주장하지 않는다.**

반면 렌더링을 중단한 상태의 Reset 무반응은 실제 AU/WebKit에서 재현했다. 이전 경로는 atomic 요청만 남기고 다음 ProcessAudio에서 처리하므로 다음 블록이 없으면 Peak +1.9/Clip이 화면에 남았다. 이때 VU도 마지막 측정값을 계속 표시했다. `evidence/native_before.log`는 이 조건에서 실패한다.

## 수정

- `main.go`: 편집기 요청에 답하는 원자적 측정 스냅샷과 블록 카운터, Reset 요청/적용 세대 추가. 오디오 상태는 오디오 스레드만 변경한다. UI에는 네이티브 Reset 확인을 즉시 보내고 다음 블록에서 코어를 초기화한다. 오디오 처리 경로에 파일 I/O·JSON·새 메모리 할당을 추가하지 않았다.
- `ui/meter.html`: 30Hz 스냅샷 요청으로 기존 호스트 파라미터 콜백 의존성을 보완했다. 네이티브 응답이 Reset 대기임을 확인하면 Peak/Clip 표시를 지운다. 블록 카운터가 750ms 이상 정지하면 IDLE, VU는 `— VU`로 표시한다. Hold OFF의 실시간 Peak/Clip은 오래된 값으로 남기지 않고, Hold ON의 기록은 Reset까지 보존한다. 이것은 입력을 가짜로 움직이는 애니메이션이 아니다.
- `scripts/build_macos.sh`: macOS Bash 3의 빈 배열+set -u 실패 수정, 버전 0.1.4.
- `main_test.go`, `scripts/au_meter_check.m`: 정지 Reset 확인·재개 처리·동시 스냅샷 검증과 실제 AU/WebKit 회귀 검사.
- `TestSignals/05_dynamic_reset_check.wav`: 18초, 48kHz stereo float32. 0–4초 L 0VU/R −6VU, 4–8초 L −12VU/R −18VU, 8–11초 무음, 11초 L 단일 샘플 1.25 clip와 큰 사인파, 13–16초 작은 신호, 16–18초 무음.

원본 목업 이미지·측정 코어·기존 프레임워크 파일은 이번 변경에서 수정하지 않았다. UI CSS/배치/스케일은 보존하고 상태 표시 동작만 변경했다. 전체 변경은 patches/0004-trackmeter-snapshot-reset-014.patch에 있다.

## 설치와 최종 테스트

로컬 Mac 작업에서 AU/VST3 설치와 기존 설치본 백업을 완료했다. 바이너리와 설치 백업은 이 저장소에 포함하지 않았다. 다른 개발자는 README의 빌드 절차를 따른다.

로컬 사용자에게는 05 WAV와 AU를 넣은 Logic 프로젝트를 별도로 준비했다. 개인 Logic 프로젝트는 이 저장소에 포함하지 않았다. 제품의 Reset은 Peak/Clip 기록 초기화이며 VU 적분기를 초기화하지 않는다. 오디오 미처리 시 VU의 `—`와 IDLE은 실제 처리 부재를 나타낸다.

원본 ZIP과 기존 사용자 프로젝트는 변경하지 않았다. 협업자에게 메시지·업로드·외부 전송은 하지 않았다.
